Matrix

Matrix is a private tool that helps its owner, Glautium Gabriel, produce and publish videos to YouTube channels he owns, with human approval and a quality gate. It uses the YouTube Data API to upload videos and to read the performance of the owner's own channels. It is not offered to other users.

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uses YouTube API Services.
