Privacy Policy – Matrix

Last updated: November 25, 2026.

1. Who we are

Matrix is a private video production and publishing tool used by one individual, Glautium Gabriel (Brazil), to publish videos to YouTube channels that he owns. It is not offered to other people. Contact: glautiumgabriel@gmail.com.

2. Data accessed through YouTube API Services

With the owner's authorization (OAuth scopes youtube.upload, youtube.readonly, youtube.force-ssl, yt-analytics.readonly and yt-analytics-monetary.readonly), Matrix: (a) uploads videos, titles, descriptions and thumbnails to the owner's own channels; (b) reads the owner's channel name and ID to confirm which channel is connected; (c) reads the list of the owner's own videos to avoid scheduling conflicts; and (d) reads performance metrics (views, watch time, click-through rate, subscribers) of the owner's own channels to learn which videos work best. No data about other users or other channels is accessed.

3. How data is used

Data is used only to publish the owner's content, show its status and show the owner's own channel performance. It is not sold, not used for advertising, and not used to profile any person. Every video is approved by a human before publication, or published under rules the owner set in advance and can switch off at any time.

4. Storage and security

Matrix runs on the owner's own computers. OAuth refresh tokens are stored locally in a protected vault on those computers and are never written to plain-text logs. There is no public server and no third-party database.

5. Sharing

We do not share YouTube user data with anyone. Content goes only to YouTube.

6. Google API Services User Data Policy

Matrix's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Matrix also follows the YouTube Terms of Service and the Google Privacy Policy.

7. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Removing a channel from Matrix deletes its stored tokens from the computer. Stored API data is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
